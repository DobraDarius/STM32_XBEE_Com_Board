# STM32_XBEE_Com_Board
Migrating a communication system from ARM7 to STM32. This project implements FreeRTOS to handle real-time tasks and manages RF data transmission via XBEE modules.  MCU: STM32 (Cortex-M)  RTOS: FreeRTOS (Real-Time Principles),  Wireless: XBEE RF Module,  Legacy: Ported from ARM7 architecture
